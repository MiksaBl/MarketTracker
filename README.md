# Market Tracker

Market Tracker is a Python application that monitors vehicle marketplaces, detects new listings, analyzes market activity trends, stores historical data in SQLite, and sends real-time Telegram notifications.

## Features

- Real-time marketplace monitoring
- New listing detection
- Activity trend analysis
- Historical data storage
- Telegram alerts
- Multiple market radar support
- Simple desktop GUI

## Technologies

- Python
- Playwright
- SQLite
- Tkinter
- Telegram Bot API

## Installation

```bash
git clone https://github.com/yourusername/market-tracker.git
cd market-tracker
pip install -r requirements.txt
playwright install chromium
```
